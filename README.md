# Heart Disease Prediction using Machine Learning

## Project Overview

This project predicts whether a patient has heart disease using machine learning classification algorithms.

## Dataset

Heart Disease Dataset

## Algorithms Used

1. Logistic Regression
2. Random Forest Classifier

## Evaluation Metrics

* Accuracy
* Precision
* Recall
* F1 Score
* ROC-AUC

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-Learn

## Results

Random Forest achieved the best performance and was selected as the final model.
